Aruba Central Migration Assistant

CLI / Classic Central → New Central

A migration readiness tool that connects to any Aruba Central tenant, discovers the entire deployment, and generates a comprehensive migration plan — without pushing any changes. It bridges the gap between legacy CLI-based templates and the new Element Profiles model, using a deterministic 10-phase pipeline to map every CLI block to its equivalent profile and automatically classify scope across a 5-level hierarchy (Global → Site Collection → Site → Device Group → Device).

  • Tested on production tenants with 124K+ devices and 776 groups
  • Full tenant discovery in ~12 minutes using ~7,300 optimized API calls
  • Deduplicates templates (e.g., 157 groups → 35 unique templates)
  • Generates a 9-tab migration intelligence report: inventory, mapping, compatibility, risks, and strategy
  • Read-only by design — write operations are blocked by default

CNX Ticket Analyzer

Support Operations / Ticket & Issue Cross-Referencing

A local-first analytics tool that cross-references customer support tickets with engineering issue-tracker entries, surfacing patterns across product component, technology area, and regression trends. It supports both a point-in-time workbook view and a live-query mode against a self-hosted issue tracker, so findings can be a snapshot or always current — all processing happens on the user's own machine, with no data uploaded to any third party.

  • Cross-references two independent ticket data sources entirely on-device
  • KPI dashboard summarizing ticket volume by customer, component, and technology area
  • Optional live-query mode against a self-hosted issue tracker via a personal access token
  • Multi-select filtering (component, label, status, priority, severity) compiled into a query client-side
  • Paginated browsing with a safety-capped export so large result sets stay manageable
